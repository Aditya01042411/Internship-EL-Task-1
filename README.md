# Task 1: Data Cleaning and Preprocessing

## Summary

Successfully completed data cleaning and preprocessing of the Customer Personality Analysis dataset using Microsoft Excel and Power Query. Separated data into individual columns using Text to Columns with the Tab delimiter, identified missing values column-wise using the `COUNTBLANK()` function, and handled missing Income values through median imputation. Formatted date columns, removed duplicate records, and handled null values and errors using Power Query. The cleaned dataset is now structured and ready for further Exploratory Data Analysis (EDA) and visualization.
